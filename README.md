# 政経BBS

**政治・経済・司法・国際・企業・社会政策について、現実世界で今起きている「金・権力・正義・不公平・敵味方・将来不安」を、匿名の人間が四六時中見に来て、議論し、反応を確認し、また戻ってくる政治経済BBS。**

このリポジトリには既にプロトタイプ実装があるが、2026-10-03 に製品の中心思想を再定義した。

## 現在の正本

- **[PRODUCT_DEFINITION.md](./PRODUCT_DEFINITION.md)** — 何を作るか / なぜそうするか / 対象範囲 / AI・ニュース・掲示板の役割
- **[DECISION_HISTORY.md](./DECISION_HISTORY.md)** — ここまでの検討経緯と、採用・棄却した案
- [implementation-plan.md](./implementation-plan.md) — 既存コードからの実装計画。**PRODUCT_DEFINITION.md と矛盾する箇所は再検討対象**
- [product-research.md](./product-research.md) — 過去の調査記録。**歴史資料であり現行正本ではない**

## 一言で言うと

作るのはニュースメディアではない。
AIサービスでもない。
投稿者をインフルエンサー化するSNSでもない。

**現実世界の政治経済で毎日起きる出来事を火種に、人間が匿名で群がって話し続ける場所。**

中心の行動ループ:

1. 何か起きていないか見る
2. 自分にどう関係するか考える
3. みんなが何を言っているか見る
4. 自分も一言書く
5. 返信や反論を見る
6. 状況が変わったかまた確認する

## 扱う範囲

- 政治・権力
- 経済・相場・税・物価・賃金・年金
- 企業・産業
- 司法・法律・裁判
- 政策に接続する社会問題
- 国際・安全保障・地政学
- 地方政治

芸能、ゲーム、恋愛、料理、一般趣味などへは初期から広げない。

## 製品原則

- **話題と群衆が主役。投稿者個人は主役にしない**
- 匿名で気軽に書ける
- 返信・引用・実況を強くする
- 初期ユーザーを細かい板へ分散させない
- 表では集約、裏ではタグ分類
- ニュースは会話の火種であり、記事転載を価値の中心にしない
- AIは新着発見、重複整理、事実抽出、タグ付け、モデレーション補助の裏方
- 政治経済の荒さは残すが、晒し・脅迫・権利侵害・bot等のサービス破壊要因は止める

## 現在のプロトタイプ

既存コードには、今回の再定義以前の思想も残っている。

現在できること:

- 論点 / スレッド表示
- コメント投稿
- 立場・評価・出典などの旧プロトタイプ機能
- 議員データ
- 通報・slow mode・ロック等の一部運営機能
- ローカルJSON保存
- Cloudflare Worker / D1向け構成

今後は、現行コードを捨てるのではなく、**PRODUCT_DEFINITION.md を基準に、普通の匿名掲示板として必要な会話機能を優先して作り直す。**

優先するもの:

- 投稿番号
- 返信 / 引用
- 匿名ID
- 未読
- 勢い
- 実況
- ニュースURLから簡単にスレを起こす導線
- タグ
- 検索
- 政治家 / 政党 / 政策 / 経済テーマ等との紐付け
- 通報 / 削除依頼 / レート制限

中心にしないもの:

- フォロワー数
- 投稿者ランキング
- 投稿者格付け
- AIによる長文ニュース生成
- AIによる意見
- 過剰な賛成 / 反対ゲーミフィケーション
- 初期からの大量カテゴリ分割

- `product-research.md`: 過去の調査

## 開発時の最優先確認

新機能を入れる前に、次を確認する。

- 「今何が起きている？」と戻る理由を強めるか
- 「みんな何を言っている？」を見る価値を強めるか
- 一言でも参加しやすくなるか
- 返信や実況で会話が続くか
- 人を無駄に分散させないか
- 投稿者個人ではなく話題と群衆を主役に保てるか
- 政治経済の範囲に収まっているか
- 法務・モデレーション上、現実的に運営できるか

この基準を満たさないものは、便利そうでも中心機能にしない。
