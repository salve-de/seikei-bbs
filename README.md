# 政治経済・事件追跡コミュニティ

政治・経済で事件が起きた時に人が集まり、状況を観戦し、本音を交わし、主張を検証し、次を予想し、決着まで追うコミュニティ。

製品原則は「事件を入口に、共同観戦を中核に、決着と行動を出口にする」。中心の流れは「今動く事件を知る → みんなと追う → 一言・質問・資料・予想で参加する → 更新へ戻る → 決着を確認する」。

現行コードは、この定義へ移行する前のプロトタイプである。事件の状態、次の予定、決着、返信・引用、未読、通知、事件内仮名は未実装であり、次の実装対象。製品判断の正本は [product-research.md](./product-research.md)。

## できること

- 家計・仕事・地域・将来・権利・安全から論点を絞り込む
- 他人の票数を見る前に、賛成・反対・判断保留を選ぶ
- 体験・意見・事実・質問を区別し、事実投稿には出典を付ける
- 「参考になった」「見方が変わった」「根拠が弱い」で投稿を評価する
- 気になる論点を端末内のウォッチ一覧へ保存する
- 一次情報と対象（政策・議員・政党・地域・経済指標）を紐づける
- 通報、slow mode、固定、ロックをローカル運営で扱う

## 起動

```bash
npm install
npm start
```

通常は `http://localhost:4173`。使用中の場合は次の空きポートへ自動で切り替わる。

## 検証

```bash
npm run check
npm test
npm run build
```

## 保存

- ローカル起動: `data/*.json`
- Sites公開: D1（論点・コメント・立場・評価・通報）
- ブラウザ: ウォッチと投票済み状態のみ

## 主な構成

- `server.js`: ローカルAPIとJSON保存
- `worker/index.js`: Sites公開APIとD1保存
- `public/`: 各画面とスタイル
- `data/`: 初期論点、コメント、議員データ
- `drizzle/`: D1初期スキーマ
- `product-research.md`: 人間の欲求から逆算した製品定義、事件体験、報酬・地位、人気サービス比較、安全運営、データ取得、反証条件

## 運用上の境界

- 匿名投稿のため、公開運用ではレート制限と通報を必須にする
- Sites公開版の運営APIは一般公開せず、権限付き運営画面は別途認証を追加してから有効化する
- 議員データは少数の公式確認済みレコードで、全国会議員の自動同期は未実装
- 削除依頼、監査ログ、選挙期間中の運用ルールは本格公開前に整備する
