# 政経板（seikei-bbs）

政治経済を題材に、人が集まり、本音を覗き、野次を飛ばし、言い合い、反応の続きを見に戻る匿名コミュニティ。

このプロジェクトの目的は、政治経済の情報を網羅することではありません。

**政治経済で今どこが盛り上がっているかを見つけ、登録なしで読み、一言で群衆に混ざれる「観客席」を作ること**です。

## 中心となる利用循環

1. 今、沸いている会場を見る
2. 同意・反論・冗談・資料投下を読む
3. 一言だけ匿名で書く
4. 返信・引用・未読が発生する
5. 論争と結果の続きを見に戻る

ニュース、政治家プロフィール、政策、企業、統計、外部URLは、この循環を始めるための材料です。運営が毎日長い記事を書く前提にはしません。

## 現在できること

- ホームで「今、沸いている会場」を確認する
- 勢い、新着、言い合い中、実況、資料あり、返信なし、ウォッチで絞り込む
- ホームの一つの入力欄から、30秒程度で会場を作る
- タイトルと最初の一言だけで詳細な会場を作る
- 登録なしで読む・書く
- レス番号、`>>番号`引用、直接返信
- スレッド内匿名ID
- 未読境界、自分への返信、ウォッチ
- 「わかる」「草」「いや違う」「ソースは？」の反応
- 任意で立場、名前、出典を追加する
- 政治家ページから関連会話を見る
- 通報、slow mode、固定、ロックを扱う

## 製品原則

- 主役は群衆の反応である
- ホームはニュース一覧ではなく、盛り上がり一覧にする
- 投稿前の必須入力を増やさない
- 政治知識、実名、支持政党、出典を参加条件にしない
- 情報を網羅するより、人を同じ会場へ集中させる
- 強い反論、皮肉、冗談、少数意見は残す
- 脅迫、晒し、私人への集中攻撃、bot、コピペ爆撃は止める
- 偽ユーザー、偽レス、偽の閲覧数で盛り上がりを演出しない

製品判断の正本は [product-research.md](./product-research.md)、実装順と完了条件は [implementation-plan.md](./implementation-plan.md) です。

## 起動

```bash
npm install
npm start
```

通常は `http://localhost:4173`。使用中の場合は次の空きポートへ自動で切り替わります。

## 検証

```bash
npm run check
npm test
npm run build
```

## 保存

- ローカル起動: `data/*.json`
- Sites公開: D1
- ブラウザ: ウォッチ、投票済み状態、匿名セッション、未読

## 主な構成

- `server.js`: ローカルAPIとJSON保存
- `worker/index.js`: Sites公開APIとD1保存
- `public/index.html`, `public/home.js`: 盛り上がり中心のホーム
- `public/thread.html`, `public/thread.js`: 会場と匿名会話
- `public/new.html`, `public/new-thread.js`: 詳細な会場作成
- `public/crowd.css`: 群衆中心の追加UI
- `data/`: 初期会場、コメント、議員データ
- `drizzle/`: D1初期スキーマ

## 次の重点

1. 返信通知のサーバー保存と任意アカウント同期
2. URL・資料を持ち込む燃料候補箱
3. 政党、企業、政策、市場の常設ページ
4. 実況モードと定例イベント
5. 次スレと継続仮名
6. 認証付き運営画面、削除依頼、監査ログ
7. 広告安全判定と収益化

## 公開前の必須条件

- レート制限と通報
- 運営APIの認証
- 削除依頼窓口
- 監査ログ
- 選挙期間中の運用ルール
- 権利侵害、脅迫、個人情報、組織攻撃への対応手順
